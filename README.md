**[Ascend — AION 2 CP Tracker](https://github.com/albertodoradofernandez-sys/ascend-datos)**<br>
Windows app that compares your character with the top players of your class (EU · NA · KR) and tells you what to upgrade first.<br>
[⬇ Download](https://github.com/albertodoradofernandez-sys/ascend-datos/releases/latest) · English & Español · auto-updates

<br clear="left">

**Built with** Rust · Tauri · Svelte · TypeScript · SQLite

**Principles**
- Uses only NCSOFT's official public character API: no memory reading, no packet sniffing, no ban risk.
- No accounts, no ads, no data collected.
- Feedback and bug reports welcome in [Issues](https://github.com/albertodoradofernandez-sys/ascend-datos/issues).
